# Responsive UI Design

This project is a Flutter application that demonstrates a responsive UI design with interactive data visualizations, including a line chart, bar charts, and a pie chart. The app adapts seamlessly to mobile, tablet, and desktop layouts.

## Features
- **Responsive Layouts**:
  - Mobile: Width < 850px
  - Tablet: Width >= 850px, width < 1100px
  - Desktop: width >= 1100px
- **Charts**:
  - Line Chart
  - Bar Chart
  - Pie Chart
- **UI-Only Design**:
  - Focused solely on the front-end design without backend integration.
